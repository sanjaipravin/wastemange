🔹 Detailed Project Description (README intro)

Waste Lens AI is an intelligent waste detection and classification platform built using AI and computer vision techniques. The system analyzes images of waste items and accurately categorizes them into recyclable, biodegradable, or non-recyclable classes.
This project aims to support smart cities, reduce landfill waste, and promote sustainable recycling practices through automation and data-driven insights.

🔹 Tech-Focused Description

An AI-based waste segregation system using deep learning and image processing to classify waste materials and support automated recycling workflows.
